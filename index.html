NO-READERS-NEEDED • Garza Group
STEP 1 Install Tampermonkey
Open Chrome Web Store → Add to Chrome
STEP 2 Turn this ON (Required)
Now do this: Right-click the address bar → Paste → press Enter
chrome://extensions/
Tampermonkey → Details → make BOTH switches BLUE: Tampermonkey = ON and Allow User Scripts = ON
If the button doesn’t copy (rare), just type this in the address bar:
chrome://extensions/
STEP 3 Install the Payroll Tool
Install Payroll Tool (Tampermonkey → Install)
Seeing code is normal. Click Install.
STEP 4 Copy New Rows (Insurance Prep)
Open Insurance Prep Sheet (Copy up to 100 rows)
Copy NEW rows only (up to 100 at a time). This gives the tool a moment to settle.
STEP 5 Use It
Open Madison — Add New Employee
Look top-right for the hovering panel → paste rows into the white box → LOAD LIST → start workflow.
Press ESC anytime to stop.
Optional: Restart Chrome/computer if you have time. If something isn’t working, John will ask you to do this anyway 🙂
Hope you enjoy. — John Covarrubias • Garza Group
