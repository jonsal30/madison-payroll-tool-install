STEP 1 Install Tampermonkey
Add Tampermonkey to Chrome
STEP 2 Turn This ON (Required)
Right-click the address bar → Paste → Enter
chrome://extensions/

Tampermonkey → Details → turn ON:
  • Tampermonkey
  • Allow User Scripts
Both switches must be BLUE
STEP 3 Install the Payroll Tool
Install Payroll Tool
Seeing code is normal. Click Install.
STEP 4 Copy New Rows
Open Insurance Prep Sheet
Copy NEW rows only (up to 100). This also gives the tool a moment to settle.
STEP 5 Use It
Open Madison — Add New Employee
Look top-right for the panel → paste rows → LOAD LIST → start your workflow.
Press ESC anytime to stop.
Optional: Restart Chrome/computer if you have time.
If something isn’t working, John will ask you to do this anyway 🙂

Hope you enjoy.
